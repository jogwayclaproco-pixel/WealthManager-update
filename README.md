# WealthManager Updates

Public release repository for the Wealth Manager Android application.

- Download signed Android APK releases from the [Releases](https://github.com/jogwayclaproco-pixel/WealthManager-update/releases) page.
- Google Play remains the recommended channel for automatic app updates.
- The application source code is maintained in a separate private repository.

Each release is published automatically from the private source repository after the Android build and validation workflow succeeds.
